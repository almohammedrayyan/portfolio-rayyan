# Fuzail's Portfolio Website

A modern, responsive portfolio website built with React, Vite, and Framer Motion featuring a teal color theme and smooth animations.

## Features

- 🎨 Modern teal color theme with gradient accents
- 📱 Fully responsive design for all devices
- ✨ Smooth animations using Framer Motion
- 🚀 Fast performance with Vite
- 🎯 Clean and intuitive navigation
- 💼 Experience section with SRM Technologies
- 🛠️ Skills showcase
- 📂 Projects portfolio
- 📧 Contact form

## Tech Stack

- React 18
- Vite
- Framer Motion
- Lucide React (icons)
- CSS3

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Preview

```bash
npm run preview
```

## Customization

1. Update personal information in the components
2. Replace placeholder image in About section
3. Add your actual projects in Projects.jsx
4. Update social media links in Hero.jsx
5. Configure contact form submission in Contact.jsx

## Deployment

This project is ready to deploy on Netlify:

1. Build the project: `npm run build`
2. Deploy the `dist` folder to Netlify
3. Configure custom domain if needed
